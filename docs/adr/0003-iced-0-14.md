# Iced 0.14 como stack de UI

O app usa Iced 0.14 em vez de GPUI. GPUI está pré-1.0, o crate oficial no crates.io está parado na 0.2.2 e a distribuição prática (`gpui-kit`) é um snapshot mantido fora do upstream; para um app pessoal de formulário e lista, a estabilidade e a arquitetura Elm do Iced pesam mais do que o visual do GPUI. A troca é cara o suficiente para registrar: a UI inteira será escrita em Iced.

## Considered Options

- **GPUI Kit 0.10**: mantém o objetivo original e traz componentes prontos, mas paga churn pré-1.0 e dependência de uma distribuição shadow.
- **egui 0.37**: protótipo mais rápido e tabela pronta, mas visual de ferramenta.
- **GTK4 + relm4**: mais nativo no GNOME, mas menos portátil e mais verboso.
